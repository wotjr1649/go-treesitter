# AGENTS.md — go-treesitter

CGO-free Go library for tree-sitter: grammar modules are generated by `tools/gen` from unmodified upstream C
(wasm → Go). `docs/README.md` maps the contracts; read only the ones your task touches.

## Rules

- Product code builds with `CGO_ENABLED=0`. A C compiler is used only by `tools/native-ref` and the race lane.
- Never edit upstream C or generated grammar modules by hand; change `tools/gen` and regenerate (CI requires the
  committed bytes). Pins in `tools/gen/pins.json` change only with explicit authority.
- Only the root `treesitter` package and generated grammar modules import `internal/engine`.
- Evidence words ("parity", "verified", "C agreement") need the level `docs/specs/validation.md` assigns. Bind results
  to their identity (commit, pins, inputs, platform); keep failures, never retry until green.
- `.scratch/` is scratch. Before deleting there, copy unique evidence to `artifacts/handoff/` with hashes.
- `tools/*` and `grammars/*` are separate Go modules: test them from their own directories.
- Merge pull requests with a merge commit (documents cite branch commit hashes). Released tags are immutable: retract,
  never move (`docs/specs/publication.md`).
