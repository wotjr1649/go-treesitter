# AGENTS.md — go-treesitter

Durable rules for every coding agent working in this repository. Changing state lives in `docs/`; read it on demand.

## What this repository is

A public, CGO-free Go library for tree-sitter (ADR-0020, ADR-0021, ADR-0022). Each grammar module is generated by
`tools/gen` from **unmodified** upstream tree-sitter runtime and grammar C (wasm translated to Go). The repository owns
the `treesitter` API and its result contract, the versioned engine ABI (`internal/engine`), the generator and its pins,
and conformance against a native C build of the same sources. It is not a re-implementation of tree-sitter and holds
no downstream application logic.

## Hard boundaries

- Product and release builds are **CGO-free** (`CGO_ENABLED=0`). A C compiler is used only by the native reference
  (`tools/native-ref`) and the diagnostic race lane.
- Upstream C is never edited. C this repository adds is its own named file. Generated grammar modules are produced by
  `tools/gen` and never hand-edited; CI regenerates them and requires the committed bytes.
- The runtime release and grammar commits are pinned in `tools/gen/pins.json`; change them only with explicit
  authority, never as a side effect of other work.
- Only the `treesitter` package and generated grammar modules import `internal/engine`. Public packages expose this
  repository's own types.
- Other repositories and checkouts are read-only from here.

## Evidence

- A claim needs the evidence level `docs/specs/validation.md` assigns to its wording. Never write "parity", "proven"
  or "verified" without it. `incremental == fresh` is not C agreement; root end == input length does not prove a
  complete parse.
- Evidence is bound to an identity (commit, pins, recipe, toolchain, inputs, platform). Never carry a result to another
  identity; if identity drifts, stop and repair provenance first.
- Preserve failures with their command, inputs, identity and output. Never retry until green, relabel a failure or
  weaken a check. A known upstream behavior becomes a signature-matched ratchet in
  `docs/validation/known-regressions.md`.
- `.scratch/` is working space. Before deleting anything there, copy its unique evidence to `artifacts/handoff/` and
  verify the hashes.

## Authority

Without asking: edit source, tests and docs here; run bounded local builds and tests; fix failures your change caused
and rerun; make scoped local commits of verified work units; continue to the next authorized unit.

Each of these needs the user's explicit authority for that act (one grant does not cover the next):

- any remote write: push, pull request, remote branch deletion, tag, release, visibility or ruleset change;
- merging into `main`, including a local merge;
- changing pins, the C-reference definition or the Release-Critical scope;
- destructive Git (`reset --hard`, `clean -fd`, history rewrite) or discarding work you did not create.

Never use a ruleset administrator bypass. Rulesets block new remote branches, any tag change or deletion, and the
creation of tags other than `v*` and `grammars/*/v*`; the owner creates anything else. Released tags are immutable: a
bad version is retracted, never moved (`docs/specs/publication.md`).

## Git and tests

- `main` holds verified work and is protected by required CI checks. Work happens on a session branch and reaches
  `main` through a pull request merged with a merge commit (documents cite branch commit hashes).
- One verified work unit per commit; record the checks that ran in the commit body.
- Run the tests closest to the change, then widen only as its blast radius or a gate requires. Generated modules,
  `tools/*` and `grammars/*` are separate Go modules: test them from their own directories.

## Completion

Finish an authorized change through the Definition of Done in `docs/specs/validation.md`: implement, test, fix,
review the diff, record evidence, commit, hand off under `artifacts/handoff/`, and give an explicit verdict. A
read-only task changes nothing. If you must stop, name the decision or environment that blocks you.
