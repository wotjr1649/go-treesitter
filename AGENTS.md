# AGENTS.md — go-treesitter

CGO-free Go library for tree-sitter: grammar modules are generated by `tools/gen` from pinned grammar C
(upstream, or owner repositories under ADR-0024 rule 7; wasm → Go). `docs/README.md` maps the contracts; read only
the ones your task touches.

## Rules

- Use **owner repository**, **owner release** and **owner CHANGELOG** for ADR-0024 rule 7, **origin** for its source history and licensing, and **upstream** for third-party sources.
- Product code builds with `CGO_ENABLED=0`. A C compiler is used only by `tools/native-ref` and the race lane.
- Never edit pinned source C (except through a recorded patch under ADR-0023) or generated grammar modules by hand;
  change `tools/gen` and regenerate (CI requires the committed bytes). `tools/gen/README.md` has the procedures
  (`Pins`, `Regenerate`, `Pin-move CI evidence`).
- Pins in `tools/gen/pins.json` (grammar commits and the CLI pin `treeSitterCLI`) change only with explicit authority,
  one pin move per PR with the `pin-move.yml` evidence. Owner-repository grammars: fix there, then move the pin to
  that repository's latest release tag and cite its CHANGELOG. Each one's committed generated files are its own pinned
  CLI's output byte for byte, without optimize-off pragmas (its AGENTS.md); with a different `treeSitterCLI` here,
  compare separately.
- Only the root `treesitter` package and generated grammar modules import `internal/engine`.
- Evidence words ("parity", "verified", "C agreement") need the level `docs/specs/validation.md` assigns. Bind results
  to their identity (commit, pins, inputs, platform); keep failures, never retry until green. Re-running a CI job that
  never ran (no runner) is allowed; note it in the PR.
- `.scratch/` is scratch. Before deleting there, copy unique evidence to `artifacts/handoff/` with hashes.
- `tools/*` and `grammars/*` are separate Go modules: test them from their own directories.
- This repository is public and every pushed commit stays public. Use one branch per task. Before each push, check
  `git diff --stat origin/main...HEAD`: only intended files, nothing from the local-only paths in `.gitignore`
  (`.scratch/`, `artifacts/handoff/`, `docs/prompts/`, `docs/plans/`), no host paths or account data, no unexpected
  large files (`docs/specs/publication.md`).
- Merge pull requests with a merge commit (documents cite branch commit hashes). Released tags are immutable: retract,
  never move (`docs/specs/publication.md`).
- Third-party upstream repositories: agents only draft; the owner posts, with an AI disclosure where the target's policy requires one (ADR-0025 decision 5).
