# Migrating from the removed `treesitter.New` / `syntax` API

The previous carrier API (`treesitter.New()`, package `syntax`, `internal/gtsadapter`) was removed with ADR-0022. It
remains in Git history at `9ad82eb` (`git show 9ad82eb:syntax/parser.go`). There is no compatibility package. This
page maps the names; the contracts are [`docs/specs/parser-result.md`](docs/specs/parser-result.md) and
[`docs/design/api-v2.md`](docs/design/api-v2.md).

| Removed (`9ad82eb`) | v2 |
|---|---|
| `treesitter.New()` → `syntax.Parser` | `treesitter.NewParser(lang, opts...)` → `*Parser`; call `Close` when done |
| `Request.Language` / `Request.Filename` (name or path detection) | a grammar module's `Language()`, e.g. `golang.Language()`; no detection by name or path |
| `Parser.Parse(ctx, Request)` → `Result` | `Parse(ctx, src, old)` → `*Tree` for incremental work, or `ParseSnapshot(ctx, src)` → `*Snapshot`; `ParseOwned` skips the source copy |
| `Request.Source` | the `src []byte` argument |
| `Request.Previous` + `Request.Edit` (byte offsets; points derived) | `Tree.Edit(InputEdit)` on the old tree, then `Parse(ctx, src, old)`; `EditFor(old, new, start, oldEnd, newEnd)` derives the points |
| `Request.Timeout` | a `ctx` deadline |
| `Limits.MaxInputBytes`, `MaxSnapshotNodes` | `WithMaxInputBytes`, `WithMaxSnapshotNodes` |
| `Limits.MemoryBudgetBytes` | `WithMaxMemoryBytes` (limits the instance's linear memory; not the same measure) |
| `Limits.IterationLimit`, `NodeLimit`, `StackDepthLimit` | none |
| `Result.Complete()` | `err == nil` (every accepted tree is checked: root end == input length) |
| `Result.Outcome` values `AcceptedClean`, `AcceptedWithErrors` | `Tree.Outcome()`; same names, now a `uint8` type. `Node.HasError()` on the root gives the same fact |
| `Timeout`, `Cancelled`, `ResourceLimit` | `*ParseError` with that `Outcome`; `errors.Is` with `ErrTimeout` (also `context.DeadlineExceeded`), `ErrCancelled` (also `context.Canceled`), `ErrResourceLimit` |
| `InvariantViolation` | `EngineFault` / `ErrEngineFault` |
| `UnsupportedInput`, `NotRun` | `InvalidInput` / `ErrInvalidInput` (nil ctx, bad option, non-UTF-8 with `WithStrictUTF8`, foreign `old`); `IncompatibleLanguage` is new |
| `EarlyStop` | none: a stopped parse returns an error and no tree |
| `Result.Diagnostics` (route, limits, token counts, arena bytes, …) | not provided; `Tree.InputBytes()`, `Tree.HasInvalidUTF8()`, `Snapshot.Len()` remain |
| `Result.Tree.Nodes()` → `[]syntax.Node` (`Type`, `Field`, `Parent` index, flags, byte/point spans) | `*Snapshot`: `Root()`, `Node(i)`, `All()`, `Walk`; `Node.Kind()`, `Field()`, `Parent()`, `IsNamed/IsExtra/IsMissing/IsError()`, `StartByte/EndByte/StartPoint/EndPoint()`; `Node.Index()` is the preorder index (the old slice was preorder too; v2 numbering is the engine's visible-node order, not guaranteed equal to the old one) |
| `Result.Tree.Close()` | `Tree.Close()` for a `*Tree`; a `*Snapshot` needs none |
| `syntax.NewIndex(nodes) (*Index, error)` | `treesitter.NewIndex(snap) *Index` or `snap.Index()` (cached) |
| `Index.OfType(t)` → `iter.Seq[int]`; `NodeAt(off)` → `(int, bool)` | `Index.OfType(kind)` → `iter.Seq[Node]`; `NodeAt(off)` → `(Node, bool)`; new `OfSymbol` |

## What behaves differently

1. **Outcomes are not a field.** A nil error means a complete tree, possibly with `ERROR`/`MISSING` nodes. Anything else is
   a `*ParseError` and no tree, so there is no partial result to inspect; the old `Result` returned diagnostics even on
   failure.
2. **Lifetimes and confinement.** The old parser owned a runtime parser per `Parse` call. A v2 `Parser` owns one engine
   instance, and the parser and its `Tree`s form one confinement unit: one goroutine at a time (misuse is reported as
   `InvalidInput`). `Close`, `Reset` and `ParserPool.Put` invalidate the parser's trees (`ErrTreeInvalidated`).
   `Snapshot` and `Node` are immutable and goroutine-safe, and outlive the parser. Use `NewParserPool` for concurrency.
3. **Editing is in place.** `Tree.Edit` leaves the tree usable only as `old` for the next `Parse`; `Snapshot` on it returns
   `ErrTreeEdited`, so take snapshots first. Incremental results are not guaranteed to equal a fresh parse.
4. **The snapshot owns its source.** `Parse` and `ParseSnapshot` copy `src` once; `ParseOwned` does not, and the caller must
   never modify the bytes afterwards. `Node.Text()` is a substring of that source. `Node` is a handle (snapshot pointer +
   index): the zero `Node` is the null node (`IsZero()`); every other method returns its zero value on it instead of panicking.
5. **Grammars are modules.** The root module has no grammar. Each of `csharp`, `golang`, `json`, `python`, `tsql`, `tsx`,
   `typescript` is its own Go module under `grammars/`, generated by `tools/gen`. Only these wave-1 grammars exist in v2;
   the other languages of the old carrier are not available (see [limitations](docs/reports/limitations.md)). Until the
   modules are tagged they resolve through a local `replace` in their `go.mod`.
