The release commit hashes cannot appear in the files that the commits contain. The `<root-release-commit>` hash exists only once the root release commit does, and the `<grammar-release-commit>` hash only after the step-4 commit. Fill them in this order: (1) the root tag points at its tested commit; (2) the step-4 commit is made and its ZIP rehearsal passes; (3) the actual selected roots, exact tags and commits, platforms, commands and results are written into the rows above in a documentation-only update; (4) the release notes link that updated table. The same update replaces every `Pending` entry.
